# Customer Feedback Data Cleaning Project | MySQL

## Project Overview
This project demonstrates SQL-based data cleaning and data quality validation using a customer feedback dataset containing 50 records and 18 columns.

The dataset includes customer details, feedback ratings, communication channels, issue categories, resolution status, response times, and order values.

## Tools Used
- MySQL
- MySQL Workbench

## Data Cleaning Tasks
- Data profiling and quality checks
- Handling missing values and NULLs
- Removing unwanted spaces and characters
- Standardizing text categories
- Validating numeric values and ranges
- Cleaning currency-formatted order values
- Validating and standardizing dates
- Identifying duplicate records for investigation
- Creating a cleaned dataset for analysis

## Data Quality Approach
The raw dataset is preserved separately from the staging and cleaned tables. Potential duplicate records and missing values are investigated rather than automatically deleted or replaced without justification.

## Project Outcome
A structured dataset prepared for exploratory SQL analysis and potential customer feedback dashboard development in Power BI.

## Dataset Note
This is a fictional dataset created for learning and portfolio demonstration. It does not represent actual customer records.
